系统化交易规则手册买卖点交易计划

现在我已加载技能，根据您的需求，这是一套系统化的交易规则体系，涵盖选股、调仓、空仓与减仓四大模块，我将为您设计完整的可执行交易计划框架。

📋 系统化交易规则手册

定位：短线/波段轮动策略 | 股票池内部切换 | 量价 + 均线 + RSI 三维过滤

【1. 选股规则 — 入场资格过滤】

核心原则：没有量的票不参与

过滤条件具体标准操作
换手率门槛换手率< 3%❌ 直接排除，不参与
换手率达标换手率≥ 3%✅ 进入候选池，继续下一步过滤

执行逻辑：

  • 每日开盘前或盘中，扫描股票池内所有标的的换手率
  • 换手率不足3%说明市场参与度低、主力未介入，强行参与容易被套在无流动性的位置
  • 换手率达标是必要条件，不是充分条件，还需结合后续规则

【2. 调仓规则 — 轮动切换机制】

核心原则：追强不追弱，在池内做相对收益

触发调仓的两个条件（满足任一即触发）：

条件A：当日持仓标的大涨超过5个点

当日涨幅 > +5% → 触发调仓评估

条件B：股票池内涨跌幅分化超过5个点

池内最强票涨幅 - 池内最弱票涨幅 > 5% → 触发调仓评估

调仓决策树：

触发调仓评估

│

├─ 池内存在未涨/涨幅较小的标的？

│ │

│ ├─ YES → 切换到未涨标的（优先换手率≥3%、未破5日线的）

│ │ ⚠️ 注意：切换前确认目标标的未破5日均线

│ │

│ └─ NO（全部上涨）→ 两种选择：

│ ① 不动，持仓不变

│ ② 减仓（若RSI同步偏高，优先减仓）

│

└─ 全部上涨且RSI > 80 → 执行减仓规则（见第四模块）

执行细节：

  • 切换时机：尾盘14:30后评估，避免日内假突破干扰
  • 切换目标：优先选择池内换手率≥3%、站上5日线、涨幅相对落后的标的
  • 切换仓位：原仓位的50%~100%转移，视目标标的确定性决定

【3. 空仓规则 — 5日均线防守体系】

核心原则：跌破均线不持仓，突破均线再考虑

空仓触发条件：

当日收盘价 < 5日均线 → 当日收盘前卖出

关键判断：收盘是否修复

盘中情况收盘情况操作
盘中跌破5日线收盘回到5日线上方✅ 修复成功，继续持有
盘中跌破5日线收盘仍在5日线下方❌ 未修复，收盘前卖出
开盘即跌破5日线全天未修复❌当日收盘前清仓

再次买入条件：

后续收盘价重新站上5日均线

+ 换手率 ≥ 3%

+ 当日无大幅放量下跌（非恐慌性反弹）

→ 重新考虑买入

执行细节：

  • 5日均线以收盘价为准，不以盘中价为准
  • 跌破后的反弹突破，需观察量能配合（缩量突破谨慎，放量突破优先）
  • 若连续2日站上5日线，确认性更强，可适当加大仓位

【4. 减仓规则 — RSI超买信号】

核心原则：RSI超买是情绪过热信号，主动降低风险敞口（如当日涨停则不考虑RSI）

减仓触发条件：

RSI（14日）> 80 且未涨停 → 仓位减半

RSI区间信号含义操作
RSI < 70正常区间持仓不变
70 ≤ RSI ≤ 80偏热，注意观察保持警惕
RSI > 80且未涨停超买，情绪过热仓位减半
RSI > 90且未涨停极度超买清仓

执行细节：

  • RSI以日线14周期为标准
  • 减仓后若RSI回落至70以下，且股价仍站上5日线，可择机补回仓位
  • 减仓不等于清仓，保留底仓以防踏空强势行情

【完整交易决策流程图】

每日收盘后 / 次日开盘前 执行以下检查：

STEP 1：换手率过滤

换手率 < 3%？→ 排除，不参与

换手率 ≥ 3%？→ 进入STEP 2

STEP 2：5日均线检查

收盘跌破5日线且未修复？→ 卖出，空仓等待

站上5日线？→ 进入STEP 3

STEP 3：RSI检查

RSI > 80？→ 仓位减半，进入STEP 4

RSI ≤ 80？→ 正常持仓，进入STEP 4

STEP 4：调仓评估

当日涨幅 > 5% 或 池内分化 > 5%？

→ 有未涨标的（且符合STEP1+2）？→ 切换

→ 全部上涨？→ 不动 或 减仓

无触发条件？→ 维持现状

【执行纪律与风险提示】

纪律条款说明
不追高调仓切换的目标标的，当日涨幅不超过3%，避免追高
不死扛跌破5日线收盘未修复，必须执行卖出，不允许"再等一天"
不满仓切换调仓时分批操作，先卖出50%，确认目标标的走势后再转移剩余
RSI减仓后不急补减仓后等RSI回落确认，不因短期反弹急于补回
量是前提任何操作前，换手率必须达标，无量不参与是铁律

【策略适用场景说明】

  • ✅适合：震荡市、结构性行情、板块轮动明显的市场环境
  • ✅适合：有明确股票池（如行业ETF成分股、主题概念股）的投资者
  • ⚠️注意：单边下跌市中，5日线频繁跌破，需提高空仓比例，减少操作频率
  • ⚠️注意：RSI在强趋势中可长期维持高位，需结合价格结构综合判断，避免过早减仓踏空

💡策略核心逻辑总结：用换手率筛选有效标的 → 用5日均线控制持仓风险 → 用涨跌幅分化驱动轮动切换 → 用RSI管理情绪过热风险。四个维度相互配合，构成完整的进出场体系。
