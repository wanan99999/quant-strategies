# 路径效率2.0 计算说明

用途：挑选近10个交易日**稳步上涨、走势平顺**的股票。
来回震荡、净涨幅很小的股票得分低；下跌的股票直接0分。

适用版本：均线多头评分策略 V1.8（评分第1项，代码参数 `Cfg.ER_N`、`Cfg.ER_ZERO`、`Cfg.ER_FULL`）

---

## 一、时间窗口

当前交易日为 t，前1交易日为 t-1，……，前10交易日为 t-10。

- 用到 t-10 至 t 共 **11 个收盘价**，形成 **10 个日间变动**（t-9 至 t 每天相对前一天的变动）。
- **C(t) 用当前交易日的实时价**（回测中为 14:55 的价格）；其余用各日收盘价。
- 收盘价统一用前复权数据；停牌日不算交易日，窗口往前顺延。

## 二、计算公式

```
位移 = C(t) − C(t-10)

路程 = Σ |C(k) − C(k-1)|      （k 从 t-9 到 t，共 10 项）

路径效率2.0（ER） = 位移 / 路程
```

- 路程为 0（10天价格完全不变）时，ER 记为 0。
- 位移**不取绝对值**：上涨为正，下跌为负，ER 取值范围为 **-1 至 1**。

| ER | 含义 |
|---|---|
| 1 | 10天每天都涨，走成一条直线 |
| 0.5 | 有回调，但总体向上 |
| 0 | 来回震荡，首尾持平 |
| 负数 | 期间下跌 |
| -1 | 10天每天都跌 |

## 三、打分

线性评分：**ER ≤ 0.2 得 0 分，ER ≥ 0.7 满分**，中间线性。

```
得分 = 100 × (ER − 0.2) / (0.7 − 0.2)，结果限制在 0 至 100 之间
```

下跌股的 ER 为负数，自然落在 0 分。

阈值依据：2026-01 至 2026-07 期间，满足"收盘 > MA5 > MA10 > MA20、5日涨幅 5%~20%"的上涨股样本（约 5.5 万个），
10日 ER 的分位为：10% 分位 0.21、中位数 0.49、75% 分位 0.64、90% 分位 0.77。
即约最差的一成样本得 0 分，约前一成半样本满分，中位数约 58 分。

## 四、与旧版（路径效率 1.0）的区别

| 项目 | 1.0 | 2.0 |
|---|---|---|
| 窗口 | 5天，t-6 至 t-1 | 10天，t-10 至 t |
| 当天价格 | 不含 | 含（实时价） |
| 分子 | 取绝对值，下跌也可能满分 | 不取绝对值，下跌为负、得 0 分 |
| 0 分线 / 满分线 | 0.3 / 1.0 | 0.2 / 0.7 |

改动原因：
1. 5天窗口里一天就占 20%，有没有赶上一根阴线，得分会在 0 和 100 之间跳；10天窗口更稳定。
2. 包含当天，当天的大阴线当天就能反映，不必等到第二天。
3. 去掉绝对值，避免"连续下跌也被当成走势平顺"。

## 五、示例

**平高电气（600312），t = 2026-10-23**

收盘价（10-09 至 10-23）：
20.34、20.36、20.38、19.89、20.23、20.74、21.42、20.66、20.67、21.33、21.50

- 日间变动：+0.02、+0.02、−0.49、+0.34、+0.51、+0.68、−0.76、+0.01、+0.66、+0.17
- 位移 = 21.50 − 20.34 = 1.16
- 路程 = 0.02 + 0.02 + 0.49 + 0.34 + 0.51 + 0.68 + 0.76 + 0.01 + 0.66 + 0.17 = 3.66
- ER = 1.16 / 3.66 = **0.317**
- 得分 = 100 × (0.317 − 0.2) / 0.5 = **23.4 分**

**大西洋（600558），t = 2026-10-23**

- 位移 = 0.14，路程 = 1.10，ER = **0.127** < 0.2 → **0 分**

**下跌股（示意）**：10天从 10.00 元每天跌到 9.00 元

- 位移 = −1.00，路程 = 1.00，ER = **−1** → **0 分**（旧版取绝对值时 ER = 1，会误得满分）
