# 海龟交易法则策略（Turtle Trading Strategy）

> 设计日期：2026-08-10
> 策略类型：趋势跟踪 / 通道突破
> 适用环境：强趋势市、单边行情
> 调仓频率：日频监控
> 来源：Richard Dennis & William Eckhardt（1983），适配A股市场

---

## 第一部分：选股策略

### 1.1 选股理念

海龟交易法则的核心理念是**"不预测，只跟随"**。选股不依赖基本面判断，而是通过**波动率标准化**筛选出适合趋势跟踪的标的，再通过**通道突破信号**决定入场时机。

### 1.2 选股池构建

#### 第一层：基础过滤

| 序号 | 条件 | 参数 | 逻辑 |
|------|------|------|------|
| S1 | 风险警示 | 排除 ST、*ST | 避免退市风险 |
| S2 | 上市时间 | 上市满250个交易日（约1年） | 确保有足够历史数据计算通道 |
| S3 | 流动性 | 近20日日均成交额 ≥ 2亿 | 保证大资金可进出 |
| S4 | 价格 | 收盘价 ≥ 5元 | 排除低价股（波动率失真） |

#### 第二层：波动率筛选（趋势市场过滤器）

海龟交易法则的核心选股逻辑：**只交易有"波动趋势"的标的**。

| 条件 | 量化规则 | 逻辑 |
|------|---------|------|
| **波动趋势** | 近50日ATR均值 > 近300日ATR均值 | 当前波动率高于历史均值，说明市场在"动" |
| **方向确认** | 近20日价格变化率绝对值 > 10% | 价格确实在朝某个方向运行 |

> ATR（Average True Range，平均真实波幅）：衡量波动率的指标。
> - True Range = Max(当日最高-当日最低, |当日最高-昨日收盘|, |当日最低-昨日收盘|)
> - ATR(N) = True Range的N日简单移动平均

#### 第三层：多品种分散

海龟交易法则强调**同时监控多个不相关标的**，通过分散化提高整体策略稳定性。

| 约束 | 规则 |
|------|------|
| 行业分散 | 同一申万一级行业最多入选2只 |
| 最终候选池 | 保持10-20只通过筛选的标的 |
| 更新频率 | 每周重新计算一次（每周五盘后） |

### 1.3 选股输出

每只候选标的输出以下信息：

| 输出项 | 计算方式 |
|--------|---------|
| ATR(20) | 近20日平均真实波幅 |
| 波动趋势比 | ATR(50) / ATR(300) |
| 唐奇安上轨 | 近20日最高价的最大值 |
| 唐奇安下轨 | 近10日最低价的最小值 |
| 当前状态 | 价格在通道内/突破上轨/跌破下轨 |

## 第二部分：交易策略

### 2.1 核心交易系统

海龟交易法则包含两套并行的交易系统：

| 系统 | 突破周期 | 退出周期 | 定位 |
|------|---------|---------|------|
| **系统1（短周期）** | 20日高点突破 | 10日低点跌破 | 捕捉中级趋势，更灵敏 |
| **系统2（长周期）** | 55日高点突破 | 20日低点跌破 | 捕捉大级别趋势，更稳定 |

> A股适配说明：原版海龟使用20/10和55/20，考虑到A股波动更大、趋势持续性较弱，系统1参数保持不变，系统2参数从55/20调整为55/20（保持原版）。

### 2.2 入场规则

#### 做多入场

| 系统 | 入场条件 | 执行 |
|------|---------|------|
| **系统1** | 当日最高价 > 过去20个交易日最高价（不含当日） | 次日开盘买入 |
| **系统2** | 当日最高价 > 过去55个交易日最高价（不含当日） | 次日开盘买入 |

#### 做空入场（如支持融券）

| 系统 | 入场条件 | 执行 |
|------|---------|------|
| **系统1** | 当日最低价 < 过去20个交易日最低价（不含当日） | 次日开盘卖出 |
| **系统2** | 当日最低价 < 过去55个交易日最低价（不含当日） | 次日开盘卖出 |

#### 入场过滤规则

| 过滤条件 | 规则 |
|---------|------|
| **上次突破失败** | 如果系统1上一次突破是假突破（最终以2N止损退出），则**跳过本次系统1信号**，仅执行系统2信号 |
| **连续突破** | 同一方向连续突破时，仅在第一次突破时入场，后续突破不加仓（除非价格朝有利方向移动了0.5N以上） |

### 2.3 仓位管理（核心特色）

海龟交易法则的仓位管理是其最独特的贡献——**基于波动率标准化（N值）的仓位计算**。

#### N值（即ATR(20)）定义

```
N = ATR(20) = 近20日真实波幅的指数移动平均
```

#### 单笔仓位计算

| 参数 | 公式 | 说明 |
|------|------|------|
| **1个单位** | 账户总资金的 1% / N | N越大（波动越大），仓位越小 |
| **单票上限** | 最多4个单位 | 分4次加仓 |
| **总持仓上限** | 最多10个单位（所有持仓合计） | 分散风险 |

> 示例：账户100万，某股票N=2元。
> 1个单位 = 100万 × 1% / 2 = 5000股（约10万元）
> 单票最多4个单位 = 20000股（约40万元，占总资金40%）

#### 金字塔加仓

| 加仓次数 | 触发条件 | 仓位 |
|---------|---------|------|
| 首次入场 | 突破信号触发 | 1个单位 |
| 第1次加仓 | 价格朝有利方向移动 0.5N | +1个单位（共2个） |
| 第2次加仓 | 价格再移动 0.5N | +1个单位（共3个） |
| 第3次加仓 | 价格再移动 0.5N | +1个单位（共4个） |

> 加仓间距 = 0.5N。例如N=2元，每上涨1元加仓一次。

### 2.4 出场规则

#### 止损出场（硬止损）

| 规则 | 公式 | 说明 |
|------|------|------|
| **2N止损** | 止损价 = 入场价 - 2 × N | 任何持仓，亏损达到2N立即退出 |

> 这是海龟法则最核心的风控规则。N值每天更新，但止损价以入场时的N值为基准，不随N值变化而调整。

#### 趋势结束出场

| 系统 | 做多出场条件 | 做空出场条件 |
|------|------------|------------|
| **系统1** | 当日最低价 < 过去10日最低价 | 当日最高价 > 过去10日最高价 |
| **系统2** | 当日最低价 < 过去20日最低价 | 当日最高价 > 过去20日最高价 |

> 系统1和系统2的持仓独立管理。同一标的可能同时持有系统1和系统2的仓位。

## 第三部分：风控策略

### 3.1 单笔风险控制

| 风控项 | 规则 | 逻辑 |
|--------|------|------|
| **单笔最大风险** | 账户总资金的 2%（2N止损 × 1单位 = 2%） | 任何单笔交易最多亏损总资金的2% |
| **单票最大风险** | 账户总资金的 8%（4单位 × 2% = 8%） | 单票满仓4单位后，最大亏损8% |
| **相关性合并** | 同一行业板块的所有持仓，合计风险敞口 ≤ 总资金的12% | 防止行业集中风险 |

### 3.2 账户级风险控制

| 风控项 | 规则 |
|--------|------|
| **总风险敞口** | 所有持仓的（单位数 × 2N）合计 ≤ 账户总资金的 20% |
| **最大持仓数** | 同时持仓不超过10个单位（所有标的合计） |
| **连续亏损熔断** | 账户从近期高点回撤 > 20%，暂停所有新开仓，仅允许平仓 |
| **月度亏损熔断** | 当月累计亏损 > 账户总资金的 10%，当月剩余交易日不再开新仓 |

### 3.3 市场环境风控

| 风控项 | 条件 | 动作 |
|--------|------|------|
| **趋势市场过滤器** | 全市场近50日ATR均值 < 近300日ATR均值（波动率萎缩） | 仅允许系统2信号，系统1信号暂停 |
| **极端波动** | VIX/波动率指数 > 近1年90%分位 | 所有新开仓单位数减半（0.5单位起） |
| **流动性危机** | 持仓标的当日跌停无法卖出 | 次日开盘市价清仓该标的 |

### 3.4 资金曲线管理

| 规则 | 说明 |
|------|------|
| **复利/缩仓** | 账户盈利时，1单位 = 最新总资金 × 1% / N（复利）；账户亏损时，1单位 = 原始资金 × 1% / N（不缩仓） |
| **再平衡** | 每周五盘后重新计算所有持仓的N值，更新止损价（仅可上移，不可下移） |

## 风险提示

- 海龟策略在**震荡市表现不佳**，会频繁触发假突破和2N止损，这是策略的固有特征（"试错成本"）
- 策略胜率通常只有35%-40%，依赖少数大趋势交易的巨大盈利覆盖多次小亏损
- A股T+1和涨跌停制度会影响止损执行，实际亏损可能超过2N
- 本策略需要严格的纪律执行，连续亏损时最容易放弃，而放弃往往发生在趋势来临前夕
