# 双均线/三均线交叉策略（Dual & Triple MA Crossover Strategy）

> 设计日期：2026-08-10
> 策略类型：趋势跟踪 / 均线交叉
> 适用环境：趋势市（双均线）/ 强趋势市（三均线）
> 调仓频率：日频监控

---

## 第一部分：选股策略

### 1.1 选股理念

均线交叉策略的选股逻辑是：**寻找均线多头排列、趋势已经确立的标的**。不预测趋势起点，而是在趋势确认后跟随。

学术研究关键发现（A股市场）：
- 均线周期越短，效果越好：日度 > 周度 >> 月度（光大证券，2026）
- 5MA和10MA对大多数行业有显著提升效果（金圆统一证券，2025）
- 均线有效性取决于行业**波动幅度**和**行情持续时间**（光大证券，2026）
- 双均线单独使用滞后性明显，震荡市频繁假信号（中信期货，2022）

### 1.2 选股池构建

#### 第一层：基础过滤

| 序号 | 条件 | 参数 | 逻辑 |
|------|------|------|------|
| S1 | 风险警示 | 排除 ST、*ST | 避免退市风险 |
| S2 | 上市时间 | 上市满120个自然日 | 确保均线可计算 |
| S3 | 流动性 | 近20日日均成交额 ≥ 1亿 | 保证可交易性 |
| S4 | 价格 | 收盘价 ≥ 3元 | 排除极端低价股 |

#### 第二层：均线多头排列筛选

> 这是选股的核心层。只有均线呈多头排列的标的才进入候选池。

**双均线策略候选池**：

| 条件 | 量化规则 |
|------|---------|
| **金叉状态** | MA10 > MA20（短期均线在长期均线上方） |
| **均线方向** | MA10近3日斜率 > 0 且 MA20近5日斜率 > 0 |
| **价格位置** | 收盘价 > MA10（价格在短期均线上方，强势确认） |

**三均线策略候选池**（更严格）：

| 条件 | 量化规则 |
|------|---------|
| **完全多头排列** | MA5 > MA10 > MA20 > MA60（四条均线从短到长依次排列） |
| **均线方向** | MA5、MA10、MA20近3日斜率均 > 0 |
| **价格位置** | 收盘价 > MA5（价格在所有均线上方） |
| **中期确认** | MA20 > MA60（中期趋势向上） |

#### 第三层：行业适配筛选

根据光大证券（2026）的研究，不同行业适合不同均线周期：

| 行业类型 | 适合均线 | 代表行业 | 选股策略 |
|---------|---------|---------|---------|
| **成长型** | 长周期均线（MA20/MA60） | 电力设备、电子、计算机、医药生物 | 三均线策略优先 |
| **周期型** | 短周期均线（MA5/MA10） | 机械、汽车、化工、有色、地产 | 双均线策略优先 |
| **主题型** | 短周期均线（MA5/MA10） | 软件开发、通信设备、机器人 | 双均线策略优先 |
| **防御型** | 不适合均线策略 | 银行、公用事业、交通运输、煤炭 | 直接排除 |

> 选股时自动识别标的所属行业类型，匹配对应的均线策略。防御型行业标的直接排除。

#### 第四层：终筛排序

对通过前三层的标的，按以下加权评分排序，取前5-10只：

| 维度 | 权重 | 量化规则 |
|------|------|---------|
| **均线发散度** | 30% | (MA5 - MA60) / MA60（发散越大，趋势越强） |
| **趋势持续性** | 25% | MA5 > MA10 的连续交易日数（越久越好，上限20日） |
| **量能配合** | 25% | 近5日均量 / 近20日均量（>1.1加分，<0.8减分） |
| **回调幅度** | 20% | (近5日最高价 - 当前价) / 近5日最高价（回调越小越好） |

### 1.3 选股输出

| 输出项 | 计算方式 |
|--------|---------|
| 综合得分 | 四维加权总分 |
| 均线状态 | MA5/MA10/MA20/MA60 数值及排列状态 |
| 均线发散度 | (MA5 - MA60) / MA60 |
| 所属行业类型 | 成长/周期/主题/防御 |
| 适配策略 | 双均线 / 三均线 |

## 第二部分：交易策略

### 2.1 双均线交易策略

#### 核心参数

| 参数 | 取值 | 说明 |
|------|------|------|
| 短期均线 | MA10（10日简单移动平均） | 快线，捕捉短期趋势 |
| 长期均线 | MA20（20日简单移动平均） | 慢线，确认中期趋势 |
| 过滤均线 | MA60（60日简单移动平均） | 趋势过滤器 |

> 参数选择依据：光大证券（2026）回测显示，A股市场10MA和20MA组合在大多数行业表现最优。

#### 入场规则

**做多入场（金叉）**：

| 条件 | 规则 |
|------|------|
| **核心信号** | MA10 上穿 MA20（金叉） |
| **趋势过滤** | 金叉发生时，MA60方向向上（MA60近5日斜率 > 0） |
| **价格确认** | 金叉当日收盘价 > MA10 |
| **执行** | 次日开盘买入 |

**做空入场（死叉，如支持融券）**：

| 条件 | 规则 |
|------|------|
| **核心信号** | MA10 下穿 MA20（死叉） |
| **趋势过滤** | 死叉发生时，MA60方向向下（MA60近5日斜率 < 0） |
| **价格确认** | 死叉当日收盘价 < MA10 |
| **执行** | 次日开盘卖出 |

#### 出场规则

| 出场类型 | 条件 | 动作 |
|---------|------|------|
| **死叉出场** | MA10 下穿 MA20 | 清仓 |
| **均线跌破** | 收盘价连续2日 < MA20 | 清仓（比死叉更早反应） |
| **MA60破位** | 收盘价 < MA60 | 清仓（中期趋势破坏） |

### 2.2 三均线交易策略

#### 核心参数

| 参数 | 取值 | 说明 |
|------|------|------|
| 短期均线 | MA5（5日简单移动平均） | 最快线，捕捉短期动能 |
| 中期均线 | MA10（10日简单移动平均） | 中速线，确认短期趋势 |
| 长期均线 | MA20（20日简单移动平均） | 慢速线，确认中期趋势 |
| 趋势基线 | MA60（60日简单移动平均） | 趋势过滤器，判断牛熊 |

#### 入场规则

**做多入场（三线金叉共振）**：

三均线策略比双均线更严格，要求**三条均线同时确认多头**：

| 条件 | 规则 |
|------|------|
| **排列确认** | MA5 > MA10 > MA20（完全多头排列） |
| **金叉确认** | MA5上穿MA10发生在最近3个交易日内（新鲜金叉） |
| **趋势过滤** | MA20 > MA60（中期趋势在长期趋势之上）且 MA60方向向上 |
| **价格确认** | 收盘价 > MA5 |
| **执行** | 次日开盘买入 |

**做空入场（三线死叉共振，如支持融券）**：

| 条件 | 规则 |
|------|------|
| **排列确认** | MA5 < MA10 < MA20（完全空头排列） |
| **死叉确认** | MA5下穿MA10发生在最近3个交易日内 |
| **趋势过滤** | MA20 < MA60 且 MA60方向向下 |
| **价格确认** | 收盘价 < MA5 |
| **执行** | 次日开盘卖出 |

#### 出场规则

三均线策略出场比双均线更灵敏：

| 出场类型 | 条件 | 动作 |
|---------|------|------|
| **排列破坏** | MA5 < MA10（短期排列反转） | 减仓50% |
| **死叉确认** | MA5下穿MA10 且 MA10下穿MA20 | 清仓 |
| **MA20破位** | 收盘价 < MA20 | 清仓 |
| **MA60破位** | 收盘价 < MA60 | 清仓（无条件） |

### 2.3 仓位管理

| 策略 | 单票仓位 | 总持仓上限 | 说明 |
|------|---------|-----------|------|
| **双均线** | 15%-20% | 5-6只 | 信号较多，分散持仓 |
| **三均线** | 20%-25% | 3-4只 | 信号较少，集中持仓 |

| 仓位调整 | 条件 | 动作 |
|---------|------|------|
| **趋势加速** | MA5与MA20的乖离率 > 8% | 减仓至半仓（趋势过热） |
| **均线粘合** | MA5/MA10/MA20三者最大差距 < 2% | 减仓至半仓（方向不明） |

## 第三部分：风控策略

### 3.1 单笔风险控制

| 风控项 | 双均线 | 三均线 | 逻辑 |
|--------|--------|--------|------|
| **硬止损** | -8% | -6% | 三均线更灵敏，止损更紧 |
| **时间止损** | 持仓15日未盈利 | 持仓10日未盈利 | 趋势预期落空 |
| **均线止损** | 收盘 < MA20 | 收盘 < MA10 | 趋势破坏 |

### 3.2 震荡市过滤（核心风控）

均线策略最大的弱点是震荡市频繁假信号。设置以下过滤机制：

| 过滤层 | 量化规则 | 动作 |
|--------|---------|------|
| **ADX过滤** | ADX(14) < 20 | 暂停所有新开仓（市场无趋势） |
| **均线缠绕过滤** | 近20日MA5与MA20交叉次数 ≥ 4次 | 暂停该标的交易（均线反复缠绕） |
| **布林带收缩** | 布林带宽(20,2) / MA20 < 5% | 暂停新开仓（波动率过低，突破在即但方向不明） |

### 3.3 账户级风险控制

| 风控项 | 规则 |
|--------|------|
| **总仓位上限** | 双均线策略总仓位 ≤ 80%，三均线策略总仓位 ≤ 100% |
| **连续亏损熔断** | 连续3笔交易亏损 → 暂停新开仓3个交易日 |
| **月度回撤熔断** | 当月账户回撤 > 8% → 当月剩余交易日不开新仓 |
| **最大回撤熔断** | 账户从高点回撤 > 15% → 清仓所有持仓，等待下月 |

### 3.4 大盘环境风控

| 大盘状态 | 双均线策略 | 三均线策略 |
|---------|-----------|-----------|
| 上证 > MA60 且 MA60向上 | 正常运作 | 正常运作 |
| 上证 > MA60 但 MA60走平 | 仓位降至50% | 仓位降至60% |
| 上证 < MA60 | 仅平仓，不开新仓 | 仅平仓，不开新仓 |
| 上证 < MA20 | 清仓 | 清仓 |

### 3.5 行业集中度风控

| 风控项 | 规则 |
|--------|------|
| 同一申万一级行业 | 最多2只，合计仓位 ≤ 30% |
| 同一行业类型（成长/周期/主题） | 合计仓位 ≤ 50% |

## 双均线 vs 三均线 对比总结

| 维度 | 双均线策略 | 三均线策略 |
|------|-----------|-----------|
| **灵敏度** | 中等 | 高 |
| **信号频率** | 较高（月均2-4次/标的） | 较低（月均1-2次/标的） |
| **假信号风险** | 震荡市较多 | 震荡市较少（更严格过滤） |
| **趋势捕捉** | 中级趋势 | 中短期趋势 |
| **适合行业** | 周期型、主题型 | 成长型 |
| **胜率** | 约40-45% | 约45-50% |
| **盈亏比** | 约2.5:1 | 约2:1 |
| **最大优势** | 覆盖面广，机会多 | 信号质量高，假突破少 |
| **最大劣势** | 震荡市磨损大 | 可能错过早期趋势 |

## 风险提示

- 均线策略本质是**滞后策略**，永远无法买在最低点、卖在最高点
- A股市场大多数时间处于震荡状态，均线策略在震荡市中会持续产生假信号和磨损
- 光大证券（2026）研究显示，银行、公用事业、交通运输等高股息行业不适合均线策略
- 策略回测表现依赖参数选择，不同市场阶段最优参数可能漂移
- 本策略基于历史统计规律，不代表未来表现
